# CSS Grid

## Краткий ответ для собеседования

**CSS Grid** — модель раскладки для **двумерных** сеток: строки и столбцы задаются у контейнера (**display: grid**), дочерние элементы размещаются в ячейках. Контейнер: **grid-template-columns** / **grid-template-rows**, **gap**, **justify-items** / **align-items**. Элементы: **grid-column**, **grid-row**, **grid-area**. На собеседовании часто спрашивают: чем Grid отличается от Flexbox, что такое `fr`, `repeat`, `minmax`, `auto-fit` / `auto-fill`, как растянуть элемент на несколько ячеек.

---

## Что такое Grid

**Grid** — раскладка по сетке: контейнер с **display: grid** (или **inline-grid**) определяет **столбцы** и **строки**, а прямые потомки попадают в ячейки или занимают несколько ячеек. Подходит для карточек, дашбордов, макетов страницы (header, sidebar, content, footer).

---

## Оси в Grid

В Grid тоже есть две оси, но они **независимы** (в отличие от Flex, где одна «главная»):

| Ось | Направление | Выравнивание элементов в ячейках | Выравнивание всей сетки в контейнере |
|-----|-------------|----------------------------------|--------------------------------------|
| **Строки (block / вертикаль)** | сверху → вниз | **align-items** | **align-content** |
| **Столбцы (inline / горизонталь)** | слева → направо | **justify-items** | **justify-content** |

- **justify-items / align-items** — как контент лежит **внутри ячейки**
- **justify-content / align-content** — как вся сетка располагается в контейнере, если она меньше контейнера
- **place-items** — краткая запись `align-items` + `justify-items` (`place-items: center`)
- **place-content** — краткая запись `align-content` + `justify-content`

## Контейнер (родитель)

| Свойство | Описание |
|----------|----------|
| **grid-template-columns** | Размеры столбцов: `1fr 1fr 1fr`, `200px 1fr`, `repeat(3, 1fr)` |
| **grid-template-rows** | Размеры строк |
| **grid-template-areas** | Именованные области макета |
| **gap** | Зазор между строками и столбцами (`row-gap`, `column-gap`) |
| **justify-items** / **align-items** | Выравнивание содержимого **внутри ячеек** |
| **justify-content** / **align-content** | Выравнивание **всей сетки** в контейнере |
| **place-items** | `align-items` + `justify-items` |
| **grid-auto-flow** | Порядок авторазмещения: `row` (по умолчанию), `column`, `dense` |
| **grid-auto-rows** / **grid-auto-columns** | Размер **неявных** строк/столбцов |

### Единицы и функции (часто спрашивают)

| Конструкция | Смысл |
|-------------|--------|
| **fr** | Доля свободного пространства: `1fr 2fr` — второе в 2 раза шире |
| **repeat(3, 1fr)** | Три равные колонки |
| **minmax(200px, 1fr)** | Не меньше 200px, растягивается до 1fr |
| **auto-fill** | Создаёт столько колонок, сколько влезет (пустые тоже остаются) |
| **auto-fit** | То же, но пустые колонки схлопываются — элементы растягиваются |

Адаптивная сетка без медиазапросов:

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}
```

## Элементы (дети)

| Свойство | Описание |
|----------|----------|
| **grid-column** | Диапазон по столбцам: `1 / 3`, `span 2`, `1 / -1` (на всю ширину) |
| **grid-row** | Диапазон по строкам |
| **grid-area** | Имя области из `grid-template-areas` или запись `row-start / col-start / row-end / col-end` |
| **justify-self** / **align-self** | Выравнивание одного элемента в своей ячейке |
| **place-self** | Краткая запись для self |

Элемент по умолчанию занимает одну ячейку; через `grid-column` / `grid-row` растягивается на несколько.

### Именованные области

```css
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar content"
    "footer footer";
  grid-template-columns: 200px 1fr;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer  { grid-area: footer; }
```

## Явная и неявная сетка

- **Явная (explicit)** — то, что задали через `grid-template-columns` / `grid-template-rows` / `grid-template-areas`
- **Неявная (implicit)** — строки/столбцы, которые Grid создаёт сам, если элементов больше, чем ячеек. Их размер — `grid-auto-rows` / `grid-auto-columns`

## Grid vs Flexbox

| | Flexbox | Grid |
|---|---------|------|
| Измерения | **Одномерный** (строка **или** столбец) | **Двумерный** (строки **и** столбцы) |
| Ось | Есть главная и поперечная | Обе оси равноправны |
| Когда | Навбар, ряд кнопок, центровка, сайдбар + контент | Макет страницы, карточки, дашборд, сложная сетка |
| Контроль | Удобно управлять элементами в одном направлении | Удобно задавать точные позиции в 2D |

Можно комбинировать: Grid для общей структуры страницы, Flex — внутри ячеек (карточки, навбар).

## Вопросы на собеседовании

| Вопрос | Краткий ответ |
|--------|----------------|
| Что такое CSS Grid? | Двумерная раскладка: display: grid задаёт строки и столбцы, дети — в ячейках |
| Чем Grid отличается от Flexbox? | Grid — 2D (строки и столбцы сразу). Flex — 1D (одна ось, перенос) |
| Что такое fr? | Доля свободного места: `1fr 2fr` — второе вдвое больше |
| Как сделать три равные колонки? | `grid-template-columns: repeat(3, 1fr);` |
| Чем auto-fit отличается от auto-fill? | Оба создают колонки «сколько влезет»; auto-fit схлопывает пустые, auto-fill — оставляет |
| Что такое minmax? | Диапазон размера: `minmax(min, max)`, часто с auto-fit |
| Как растянуть элемент на несколько ячеек? | `grid-column: 1 / 3;` или `span 2` |
| Чем justify-items отличается от justify-content? | items — внутри ячейки; content — вся сетка в контейнере |
| Что такое явная и неявная сетка? | Явная — задали template; неявная — Grid дорисовал сам под лишние элементы |
| Зачем grid-template-areas? | Именованные зоны макета — удобно читать и менять структуру |

---

## Кратко запомнить

**Grid** — двумерная сетка: `grid-template-columns` / `rows`, **gap**, **fr**. Элементы — в ячейках; **grid-column** / **grid-row** / **grid-area** — несколько ячеек. **auto-fit + minmax** — адаптив без медиазапросов. Для одномерных рядов — Flexbox, для макетов и сеток — Grid.
