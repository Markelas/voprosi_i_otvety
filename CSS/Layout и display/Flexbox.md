# Flexbox

## Краткий ответ для собеседования

**Flexbox** (Flexible Box Layout) — модель раскладки для **одномерного** размещения элементов в строку или столбец. Родитель получает **display: flex**, дочерние элементы становятся flex-элементами и выстраиваются по **главной оси** (main axis). Основные свойства контейнера: **flex-direction**, **justify-content** (главная ось), **align-items** (поперечная ось), **flex-wrap**. У элементов: **flex-grow**, **flex-shrink**, **flex-basis** (или кратко **flex**). На собеседовании часто спрашивают: что такое главная и поперечная ось, чем justify-content отличается от align-items, что делает flex: 1, когда Flex, а когда Grid.

---

## Что такое Flexbox

**Flexbox** — способ раскладки: контейнер с **display: flex** (или **inline-flex**) управляет расположением своих **прямых** потомков вдоль одной оси. Элементы можно выравнивать, распределять свободное место и переносить на новую строку/столбец.

---

## Главная и поперечная ось

Это самый частый вопрос про Flex на собеседовании.

| Ось | Что это | Чем управляется |
|-----|---------|-----------------|
| **Главная (main axis)** | Ось, вдоль которой идут flex-элементы | **flex-direction** задаёт направление; **justify-content** — выравнивание |
| **Поперечная (cross axis)** | Перпендикулярна главной | **align-items** / **align-self** / **align-content** |

### Как flex-direction меняет оси

| flex-direction | Главная ось | Поперечная ось |
|----------------|-------------|----------------|
| **row** (по умолчанию) | слева → направо (горизонталь) | сверху → вниз (вертикаль) |
| **row-reverse** | справа → налево | сверху → вниз |
| **column** | сверху → вниз (вертикаль) | слева → направо (горизонталь) |
| **column-reverse** | снизу → вверх | слева → направо |

Важно: при `flex-direction: column` **justify-content** работает по **вертикали**, а **align-items** — по **горизонтали**. Оси «меняются местами» относительно привычного row.

```css
.container {
  display: flex;
  flex-direction: row; /* главная = горизонталь */
  justify-content: center; /* по главной */
  align-items: center;     /* по поперечной */
}
```

## Контейнер (родитель)

| Свойство | Описание |
|----------|----------|
| **flex-direction** | row, row-reverse, column, column-reverse — направление главной оси |
| **justify-content** | Выравнивание по **главной** оси: flex-start, flex-end, center, space-between, space-around, space-evenly |
| **align-items** | Выравнивание по **поперечной** оси: stretch (по умолчанию), flex-start, flex-end, center, baseline |
| **align-content** | Выравнивание **нескольких линий** (когда есть wrap) по поперечной оси. Без wrap почти не влияет |
| **flex-wrap** | nowrap (по умолчанию), wrap, wrap-reverse — перенос на новую линию |
| **flex-flow** | Краткая запись: flex-direction + flex-wrap |
| **gap** | Зазор между элементами (row-gap / column-gap) |

### justify-content vs align-items vs align-content

- **justify-content** — распределение элементов вдоль **главной** оси
- **align-items** — выравнивание элементов вдоль **поперечной** оси (в пределах одной линии)
- **align-content** — распределение **линий** по поперечной оси, когда элементов несколько рядов/столбцов (`flex-wrap: wrap`). Если wrap нет — не работает

## Элементы (дети)

| Свойство | Описание |
|----------|----------|
| **flex-grow** | Насколько элемент **растёт** за счёт свободного места (по умолчанию 0) |
| **flex-shrink** | Насколько **сжимается** при нехватке места (по умолчанию 1) |
| **flex-basis** | Базовый размер до распределения места (`auto`, `0`, `200px`, `%`) |
| **flex** | Краткая запись: `grow shrink basis` |
| **align-self** | Переопределить align-items для одного элемента |
| **order** | Порядок отображения (по умолчанию 0). Меняет визуальный порядок, не DOM |

### Шорткаты flex (часто спрашивают)

| Запись | Эквивалент | Смысл |
|--------|------------|--------|
| **flex: 1** | `1 1 0%` (часто) | Занять доступное место, равномерно с соседними |
| **flex: auto** | `1 1 auto` | Расти/сжиматься от своего размера контента |
| **flex: none** | `0 0 auto` | Не расти и не сжиматься |
| **flex: 0 0 200px** | — | Фиксированный размер 200px |

**flex: 1** — типичный способ «растянуть» элемент на всё свободное пространство.

---

## Когда использовать

Flexbox удобен для: центровки, навбара, ряда кнопок/карточек, сайдбара + контента, распределения места между блоками, простых адаптивных рядов с `flex-wrap`.

Для сложных **двумерных** сеток (строки и столбцы одновременно, области макета) — **CSS Grid**.

## Вопросы на собеседовании

| Вопрос | Краткий ответ |
|--------|----------------|
| Что такое Flexbox? | Одномерная модель раскладки: display: flex выстраивает детей по главной оси |
| Чем главная и поперечная ось отличаются? | Главная — направление элементов (flex-direction); поперечная — перпендикулярно. justify-content — по главной, align-items — по поперечной |
| Что будет при flex-direction: column? | Главная ось станет вертикальной: justify-content — по вертикали, align-items — по горизонтали |
| Чем align-items отличается от align-content? | align-items — выравнивание элементов в линии; align-content — распределение линий при wrap |
| Что делает flex: 1? | Элемент растёт и сжимается, занимает доступное место (обычно grow=1, shrink=1, basis=0%) |
| Чем flex-grow отличается от flex-basis? | basis — стартовый размер; grow — как делить **свободное** место после basis |
| Что делает order? | Меняет визуальный порядок элементов, не меняя порядок в DOM (осторожно с a11y) |
| Flexbox или Grid? | Flex — одна ось (ряд/столбец). Grid — две оси сразу (строки и столбцы) |
| Как центрировать блок? | `display: flex; justify-content: center; align-items: center;` |

---

## Кратко запомнить

**Flexbox** — одномерная раскладка. **Главная ось** задаётся `flex-direction`, по ней работает `justify-content`. **Поперечная** — перпендикулярна, по ней `align-items`. При `column` оси «меняются». **flex: 1** — занять свободное место. Для двумерных сеток — Grid.
