### **Задача 1: UndefinedToNull<T>**

**Условие:**
Реализуйте тип `UndefinedToNull`, который преобразует все `undefined` в `null`, включая вложенные объекты и массивы.

**Начальный код:**
```ts
// TODO: Реализовать UndefinedToNull
type A = UndefinedToNull<string>    // string
type B = UndefinedToNull<undefined> // null
type C = UndefinedToNull<[undefined, null]> // [null, null]
type D = UndefinedToNull<{
  a: undefined,
  b: [1, undefined]
}> // {a: null, b: [1, null]}
```

**Решение:**
```ts
type UndefinedToNull<T> = 
  T extends undefined 
    ? null 
    : T extends object 
      ? { [K in keyof T]: UndefinedToNull<T[K]> }
      : T;

type A = UndefinedToNull<string>    // string ✅
type B = UndefinedToNull<undefined> // null ✅
type C = UndefinedToNull<[undefined, null]> // [null, null] ✅
type D = UndefinedToNull<{
  a: undefined,
  b: [1, undefined]
}> // {a: null, b: [1, null]} ✅
```

**Объяснение:**
- Если `T` это `undefined` → возвращаем `null`
- Если `T` это объект → рекурсивно обрабатываем все свойства
- Иначе → возвращаем `T` как есть

### **Задача 2: DiffKeys<A, B>**

**Условие:**
Реализуйте тип `DiffKeys`, который возвращает ключи, которые есть либо в `A`, либо в `B`, но не в обоих одновременно.

**Начальный код:**
```ts
// TODO: Реализовать DiffKeys
type A = DiffKeys<{a: 1, b: 2}, {b: 1, c: 2}>;
// Должно быть: 'a' | 'c'
```

**Решение:**
```ts
type DiffKeys<
  A extends Record<string, any>,
  B extends Record<string, any>
> = Exclude<keyof A, keyof B> | Exclude<keyof B, keyof A>;

type A = DiffKeys<{a: 1, b: 2}, {b: 1, c: 2}>;
// 'a' | 'c' ✅
```

**Объяснение:**
- `Exclude<keyof A, keyof B>` — ключи в `A`, но не в `B`
- `Exclude<keyof B, keyof A>` — ключи в `B`, но не в `A`
- Объединяем через `|`
