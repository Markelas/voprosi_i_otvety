## 🔑 Что такое `key` в списках React

**`key`** — это специальный атрибут, который помогает React отличать элементы списка при повторных рендерах.

Используется только внутри массивов и динамических списков (`map`).

---

### 🎯 Для чего нужен:

React использует `key` для **диффинга (reconciliation)**, чтобы понять:
- 🔹 Какой элемент остался тем же
- 🔹 Какой добавился
- 🔹 Какой удалился

Это позволяет **минимизировать перерисовки**.


Ключи помогают React эффективно сравнивать старую и новую версию списка. Если ключи уникальны и неизменны, React:

- Правильно идентифицирует каждый элемент.
- Избегает ненужного перерисовывания элементов, которые не изменялись.
- Поддерживает корректное состояние вложенных компонентов.

---

### ⚠️ Что произойдёт, если `key` не использовать?

Если `key` не уникальный или отсутствует, React будет использовать **индекс массива**, что плохо при:

- ❌ **Вставке / удалении в середину списка** → компоненты потеряют состояние (например, `input`)
- ❌ **Возможны непредсказуемые баги**, например: у `input` поля сохраняется текст, хотя должно обновиться

---

### ✅ Правильное использование:

```js
const items = [{ id: 1, name: 'Item 1' }, { id: 2, name: 'Item 2' }];

// ✅ Хорошо — используем уникальный ID
items.map(item => <Item key={item.id} name={item.name} />);

// ❌ Плохо — используем индекс (только если список статичен)
items.map((item, index) => <Item key={index} name={item.name} />);
```

---

### 💡 Правило:

**Всегда используй уникальные стабильные идентификаторы** (например, `id` из базы данных), а не индексы массива!
